# Gest-o-de-estoque
Sistema de Gestão de Estoque em Python com cadastro de produtos, registro de entradas e saídas e consulta de estoque em tempo real. Inclui alertas automáticos para estoque baixo e cálculo do preço total do inventário. Ideal para pequenos negócios que precisam de um controle simples e eficiente de mercadorias.
